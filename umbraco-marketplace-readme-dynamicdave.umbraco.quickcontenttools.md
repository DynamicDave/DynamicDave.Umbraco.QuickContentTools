# Quick Content Tools

The small actions you need every day, one click away. Quick Content Tools adds copy and open actions to the actions menu of documents, in the content tree and in the document workspace.

## Features

- Copy the URL or the relative URL
- Copy the content key (GUID) or the node ID (shown in the menu)
- Copy the page title or the backoffice URL
- Open the page on the website in a new tab
- URLs and titles follow the backoffice language; access checks match Umbraco's own

## Compatibility

- Umbraco **17 and 18** (.NET 10)
- Backoffice UI in English, Dutch, German, French and Danish
- Free and open source (MIT)

## Getting started

```
dotnet add package DynamicDave.Umbraco.QuickContentTools
```

No configuration needed. Full documentation: [README on GitHub](https://github.com/DynamicDave/DynamicDave.Umbraco.QuickContentTools/blob/main/src/DynamicDave.Umbraco.QuickContentTools/README.md).
